## 워게임 1. Carve Party

호박을 10000번 터치하면 플래그가 보이는 프로그램인데, 진짜 호박을 10000번 누르라고 하진 않았을 것 같아서 개발자 도구를 열어 소스 코드를 보았다.
맨 아래쪽 줄을 보면 count 값이 있었는데, 1로 되어 있던 것을 100 혹은 10000으로 바꾸어 한 번에 해보려 했지만 정상 작동되지 않았다. 
그 이유를 알아보니 이 프로그램은 카운트를 1부터 순차적으로 증가시켜 10000까지 도달해야만 하도록 코딩이 돼 있었다. 그래서 한 번에 건너 뛰게 되면 프로그램이 고장 날 수 밖에 없었던 것이다.
해결 법은 콘솔 창에 카운트를 1부터 10000까지 순차적으로 증가하게 하는 코드를 집어 넣고 실행하는 것이었다. 
반복문으로 순차적으로 반복하게 한 뒤, 
txt = pumpkin.map(x => String.fromCharCode(x)).join('')
이 코드를 이용해 숫자를 아스키 문자로 변환하고 조합하는 코드를 만들고,
최종적으로 콘솔에 출력하게 만들면 플래그가 뜨게 된다.


## 워게임 2. Flying Chars

이 문제 서버를 열어보니 화면에 문자들이 왼쪽에서 오른쪽으로 빠르게 움직이고 있는 것을 볼 수 있다.
소스 코드를 보니 
const img_files = ["/static/images/10.png", "/static/images/17.png", "/static/images/13.png", "/static/images/7.png","/static/images/16.png", "/static/images/8.png", "/static/images/14.png", "/static/images/2.png", "/static/images/9.png", "/static/images/5.png", "/static/images/11.png", "/static/images/6.png", "/static/images/12.png", "/static/images/3.png", "/static/images/0.png", "/static/images/19.png", "/static/images/4.png", "/static/images/15.png", "/static/images/18.png", "/static/images/1.png"];
움직이는 문자 순서가 이렇다는 것을 알 수 있었고, 왼쪽 파일 목록을 보니 0 부터 19 까지 문자 사진들이 차례로 들어있었다.
따라서 코드를 따로 조작하지 않고도 이것들을 순서대로 정렬해서 보면 답이 나온다는 것을 알 수 있었다.


## 워게임 3. simple-web-request

이 문제 사이트를 들어가 보니 param과 param2를 입력할 수 있었고, 소스 코드를 보니 무언가 힌트가 될 만한 것은 없었다.
문제 파일을 다운 받아 app.py를 열어보니 
if prm1 == "getget" and prm2 == "rerequest":
            return redirect(url_for("step2", prev_step_num = step1_num))
        return render_template("step1.html", text = step1_text)
이런식으로 답이 나와있었다.

getget과 rerequest를 입력하고 제출을 누르니 다음 단계로 넘어갔다.
코드를 아래로 내리다 보니 똑같은 형식의 코드가 또 있어서 보았더니 정답이 있었다.
if prm1 == "pooost" and prm2 == "requeeest":
                    return render_template("flag.html", flag_txt=FLAG)

pooost와 requeeest를 입력해 제출을 누르니 플래그가 떴다.
