## 1. 리눅스 패키지
 - 리눅스 패키지는 리눅스에서 프로그램을 실행하기 위해 필요한 파일들의 집합을 포함하는 설치 파일.
 -  소스 패키지: 사용자가 집접 해당 패키지를 컴파일 해야 하므로 오류 발생 가능성 있음. 하지만 사용자가
   소스 코드를 자유롭게 변경할 수 있다는 장점이 있음.
 - 바이너리 패키지: 이미 컴파일 된 바이너리를 제공하기 때문에 오류 발생이 적음. 하지만 컴파일 된 바이너리가 필요로 하    는 의존성 파일들을 제대로 제공하지 않는 경우 오류 발생.
 - 저수준 패키지 관리 도구: dpkg와 rpm이 있음.
 - 고수준 패키지 관리 도구: apt, apt-get와 yum, dnf가 있음.

## 3. 네트워크
 - 각 계층에서 사용하는 통신 규약이 있으며 이를 프로토콜이라 부른다.

* OSI 7계층
    - 응용 계층
    - 표현 계층
    - 세션 계층
    - 전송 계층
    - 네트워크 계층
    - 데이터 링크 계층
    - 물리 계층
 
* 네트워크 상태 확인 및 변경
  - 네트워크 인터페이스는 컴퓨터나 네트워크가 통신하기 위한 물리적 또는 가상의 연결 지점을 의미함. 네트워크 인터페이스는 네트워크 인터페이스 카드가 존재하며 LAN 혹은 WiFi에서 받은 전기 신호를 디지털 신호로 변환함.
 
* 네트워크 접속(nc)
  - nc는 netcat의 줄임말로 TCP 혹은 UDP 연결을 읽거나 기록하는 프로그램. 사용자는 nc를 이용해 TCP 혹은 UDP를 지원하는 네트워크 환경에 접속할 수 있음.
  - <img width="1078" height="916" alt="스크린샷_26-7-2026_213747_learn dreamhack io" src="https://github.com/user-attachments/assets/f70ac29c-1289-4f84-9615-7c165c11b398" />


* 파일 다운로드
  - wget은 web get의 약자로 웹 상의 파일을 다운로드 받기 위한 명령어이다. HTTP, HTTPS, FTP 프로토콜을 사용하는 사이트의 파일들을 다운로드할 수 있다.

* 네트워크 데이터 전송
  - curl은 client URL의 약자로 특정 프로토콜을 이용해 URL로 데이터를 전송한다. 서버에 데이터를 보내거나 가져올 때 사용한다.
 

## 4. vim
 - vim은 명령모드와 편집 모드 두가지의 상태가 있다. 프로그램을 실행하는 순간 명령 모드에 들어가게 되고 명령 모드에서 명령을 내려 편집 모드로 들어갈 수 있으며 편집모드에서 esc를 입력해 다시 돌아올 수 있음.
 - 편집, 커서 이동, 복사, 검색, 저장 등이 가능함.
