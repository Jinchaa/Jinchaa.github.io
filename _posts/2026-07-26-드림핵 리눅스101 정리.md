## 1. 리눅스 기본 명령어들

 1. 셸
  - 셸은 유저가 리눅스 시스템을 이용할 수 있는 인터페이스이다. 유저에게 입력을 받고 운영체제가 그것을 프로그램으로 처리하면 그 결과를 유저에게 출력한다.

    user@user-VirtualBox:~$ - 셸 프롬프트

    1. id : 실행 시 현재 유저의 유저 ID와 해당 유저가 속해 있는 그룹 ID를 보여줌
    2. sudo apt update : apt 명령어로 설치 가능한 소프트웨어 패키지 목록을 업데이트한다.
    3. sudo apt upgrade : 리눅스에 설치된 소프트웨어 패키지의 버전을 업그레이드한다.
    4. pwd : Print Working Directory의 줄임말. 현재 작업 중인 디렉토리의 경로를 출력한다.
    5. ls : List의 줄임말로 디렉토리의 내용을 출력한다.
    6. cd : Change Directory의 줄임말로 작업중인 디렉토리를 변경하는 명령어이다.
      * 절대경로 : /를 시작으로 모든 경로를 적어 표현.
      * 상대경로 : 현재 디렉토리를 기준으로 상위 디렉토리 또는 하위 디렉토리로 뻗어 나가는 경로.
    7. mkdir : Make Directory의 줄임말로 디렉토리를 생성함.
    8. touch : 비어있는 새로운 파일을 만들 때 사용
    9. mv : Move의 줄임말로 파일이나 디렉토리의 위치를 옮길 때 사용하는 명령어. 파일이나 디렉토리의 이름을 변경할 때에도 사용 가능.
    10. rm : Remove의 줄임말로 파일이나 디렉토리를 삭제하는 명령어.
    11. cat : 파일의 내용을 출력하는 명령어.
    12. file : 파일의 유형을 출력하는 명령어
    13. echo : 셸에 유저가 입력한 텍스트를 출력함.
    14. cp : Copy의 줄임말로 파일이나 디렉토리를 복사하는 명령어.
    15. grep : 전체에서 특정 문자열을 찾을 때 사용.
    16. man : Manual의 줄임말로 특정 명령어의 매뉴얼을 보여주는 명령어.
    17. curl : client URL의 줄임말로 서버에 데이터를 보내거나 서버로부터 데이터를 받는 데이터 전송 명령어.

2. 와일드카드
 - 와일드카드는 리눅스에서 임의의 다른 문자를 나타낼 수 있는 특수 문자들을 의미.

3. 리다이렉션
 - 리다이렉션은 모니터에 나타나는 표준 출력 혹은 키보드로 입력하는 표준 입력을 다른 곳으로 변경하는 작업.

4. 파이프
 - 파이프는 리다이렉션의 한 형태로, 명령어 결과 표준 출력을 다른 명령어의 표준 입력으로 보낼 때 사용.





## 2. 권한

1. 유저(user)와 그룹(group)
 : 파일이나 디렉토리와 같은 시스템 자원에 유저가 접근하면 유저의 UID와 해당 유저가 속한 그룹의 GID를 확인해 정당한 권한을 가지고 있는지를 판단해 접근을 제어함.


2. 파일 및 디렉토리 권한
 : 소유자는 파일 또는 디렉토리의 권한을 수정할 수 있는 능력을 가지고 있음. 소유자는 이를 통해 소유자 또는 소유 그룹에 포함된 유저가 해당 파일 또는 디렉토리에 대해 얼마만큼 접근 권한을 가질 것인지 설정할 수 있다.
    읽기, 쓰기, 실행의 접근 권한이 있다.

    r: 서유자가 파일 또는 디렉토리에 읽기 권한을 가짐.
    w: 소유자가 파일 또는 디렉토리에 쓰기 권한을 가짐.
    x: 소유자가 파일 또는 디렉토리에 실행 권한을 가짐.


3. 파일 및 디렉토리 권한 명령어
    1. chmod: 파일 권한 변경
    2. chown: 파일 소유자 혹은 소유 그룹을 변경 

4. 특수 권한
    1. setuid: 일반 사용자가 파일을 실행하면 파일 소유자 권한으로 실행됨.


## 3. 디렉토리 구조

1. 루트 디렉토리 /
    1. /bin: 일반 유저가 사용할 수 있는 기본적인 명령어나 프로그램을 담음.
    2. /boot: 시스템 부팅에 필요한 파일을 담음.
    3. /dev: 장치를 나타내는 파일을 담고 있는 디렉토리.
    4. /etc: 운영체제나 운영체제 위에서 동작하는 서비스의 설정 파일들을 담고 있는 디렉토리.
    5. /home: 각 일반 유저의 홈 디렉토리를 담고 있는 디렉토리.
    6. /lib: 시스템에 필요한 라이브러리 파일들을 담고 있는 디렉토리.
    7. /opt: 소프트웨어 패키지들을 담는 디렉토리.
    8. /proc: 리눅스 커널 자원에 접근할 수 있는 파일과 프로세스를 나타내는 파일을 담고 있음.
    9. /root: root 유저의 홈 디렉토리.
    10. /sbin: 기본적인 유저 명령어나 프로그램을 가지고 있는 디렉토리.
    11. /tmp: 유저나 프로그램이 임시로 파일을 생성해야할 때 사용할 수 있는 디렉토리.
    12. /usr: 사용자 바이너리, 문서, 라이브러리, 헤더 파일 등을 담고 있는 디렉토리.
    13. /var: 프로그램이나 시스템이 실시간으로 가변적인 파일을 사용하고 저장해야 할 때 활용하는 디렉토리.


## 4. 리눅스
 - 리눅스는 Unix-like 운영체제이다. 대부분의 컴퓨터 사용자가 사용하는 Window, macOS와 달리 오픈소스이며 사용자는 자유롭게
    코드를 변경하여 사용할 수 있다.


## 5. 셸(Shell)
 - 운영체제는 유저 레벨과 커널 레벨로 구분된다. 이 둘 사이를 연결해주는 프로그램이 셸이다.
 - 셸은 크게 GUI Shell과 CLI Shell로 나뉜다.
 - GUI 셸은 직관적으로 사용할 수 있지만 그래픽 작업이 자원을 많이 소모하기 때문에 실행속도가 느리다.
 - CLI 셸은 아이콘과 같은 이미지를 보여주지 않기 때문에 비직관적이고, 명령어들을 암기해야 한다는 단점이 있으나 실행속도가 빠르고 정밀한 작업을 수행하기 좋다


## 6. 셸의 종류
1. 터미널(Terminal) : CLI 셸을 GUI 셸 위에서 사용할 수 있도록 하는 프로그램이다. 
2. sh: Bourne SHell은 유닉스 버전 7의 기본 셸이다. 
3. bash: sh를 대체하기 위해 작성한 유닉스 셸. GNU 운영체제와 리눅스, macOS 등의 기본 셸로 탑재됨.
4. zsh: Z Shell은 bash, ksh등의 다양한 셸의 장점을 모아 만든 확장형 셸로 커스텀하기 용이하며 설치도 간편함.


## 7. 리눅스 디렉터리 경로와 목적
1. /bin: 기본 실행 프로그램 저장
2. /boot: 리눅스 커널과 부트로더 저장
3. /dev: 디바이스 장치 파일
4. /etc: 시스템 환경 설정 파일 저장
5. /home: 사용자 별 홈 디렉토리 담는 디렉토리
6. /lib: 공유 라이브러리 파일 저장
7. /lost+found: 부팅 시 파일 시스템에 문제가 생기는 경우 복구에 사용하기 위함.
8. /media: 물리적 저장 장치들을 마운트 하기 위해 사용.
9. /mnt: 물리적 저장 장치들을 마운트 하기 위해 사용.
10. /opt: 추가적인 프로그램들을 설치하기 위해 사용.
11. /proc: 커널 관련 정보를 저장하기 위한 디렉터리.
12. /root: 루트의 홈 디렉토리.
13. /sbin: 시스템 관리자를 위한 프로그램 저장.
14. /srv: 서버 시스템에서 사용되는 데이터 저장.
15. /tmp: 임시 파일 저장.
16. /usr: 사용자 어플리케이션들을 지원하기 위한 파일들을 저장
17. /var: 로그 파일 저장
